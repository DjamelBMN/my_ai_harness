# Exercice d'entraînement : Les identités remarquables en classe de troisième / seconde

Cet exercice complet permet de réviser et de maîtriser l'utilisation des trois identités remarquables fondamentales en algèbre. Il est structuré en plusieurs parties progressives allant du calcul littéral de base à la résolution de problèmes et à la modélisation géométrique.

---

## Rappels de cours

Pour tous nombres réels $a$ et $b$ :
1. **Carré d'une somme** : 
   $$(a + b)^2 = a^2 + 2ab + b^2$$
2. **Carré d'une différence** : 
   $$(a - b)^2 = a^2 - 2ab + b^2$$
3. **Produit de la somme par la différence** : 
   $$(a - b)(a + b) = a^2 - b^2$$

---

## Partie 1 : Développement et réduction

Développer et réduire les expressions algébriques suivantes :

* $A = (x + 3)^2$
* $B = (2x - 5)^2$
* $C = (3x - 4)(3x + 4)$
* $D = (5x + 2)^2 - (3x - 1)(3x + 1)$

### Corrigé détaillé de la Partie 1

* **Expression $A$** :
  $$(x + 3)^2 = x^2 + 2 \times x \times 3 + 3^2 = x^2 + 6x + 9$$

* **Expression $B$** :
  $$(2x - 5)^2 = (2x)^2 - 2 \times (2x) \times 5 + 5^2 = 4x^2 - 20x + 25$$

* **Expression $C$** :
  $$(3x - 4)(3x + 4) = (3x)^2 - 4^2 = 9x^2 - 16$$

* **Expression $D$** :
  On développe séparément les deux parties :
  $$(5x + 2)^2 = 25x^2 + 20x + 4$$
  $$(3x - 1)(3x + 1) = 9x^2 - 1$$
  Puis on soustrait en faisant attention aux signes :
  $$D = (25x^2 + 20x + 4) - (9x^2 - 1)$$
  $$D = 25x^2 + 20x + 4 - 9x^2 + 1$$
  $$D = 16x^2 + 20x + 5$$

---

## Partie 2 : Factorisation

Factoriser les expressions suivantes en utilisant l'identité remarquable adéquate :

* $E = x^2 - 10x + 25$
* $F = 9x^2 + 12x + 4$
* $G = 49x^2 - 64$
* $H = (x + 1)^2 - 4$

### Corrigé détaillé de la Partie 2

* **Expression $E$** :
  $$x^2 - 10x + 25 = x^2 - 2 \times x \times 5 + 5^2 = (x - 5)^2$$

* **Expression $F$** :
  $$9x^2 + 12x + 4 = (3x)^2 + 2 \times (3x) \times 2 + 2^2 = (3x + 2)^2$$

* **Expression $G$** :
  $$49x^2 - 64 = (7x)^2 - 8^2 = (7x - 8)(7x + 8)$$

* **Expression $H$** :
  Il s'agit d'une différence de deux carrés $A^2 - B^2$ avec $A = (x + 1)$ et $B = 2$ :
  $$(x + 1)^2 - 4 = [(x + 1) - 2][(x + 1) + 2] = (x - 1)(x + 3)$$

---

## Partie 3 : Application géométrique et calcul mental

1. **Calcul mental astucieux** :
   En remarquant que $102 = 100 + 2$, calculez $102^2$ en utilisant une identité remarquable.
   De même, calculez $99 \times 101$ à l'aide d'une identité remarquable.

2. **Problème géométrique** :
   Soit un carré de côté $x + 4$ (où $x > 0$).
   * Exprimez son aire $A_1$ en fonction de $x$ sous forme développée.
   * On retire à ce carré un coin carré de côté $2$. Exprimez l'aire restante $A_2$ sous forme factorisée en utilisant une différence de deux carrés, puis développez-la.

### Corrigé détaillé de la Partie 3

1. **Calcul mental** :
   * $102^2 = (100 + 2)^2 = 100^2 + 2 \times 100 \times 2 + 2^2 = 10000 + 400 + 4 = 10404$.
   * $99 \times 101 = (100 - 1)(100 + 1) = 100^2 - 1^2 = 10000 - 1 = 9999$.

2. **Problème géométrique** :
   * L'aire initiale est $A_1 = (x + 4)^2 = x^2 + 8x + 16$.
   * L'aire du petit carré retiré est $2^2 = 4$. L'aire restante est donc :
     $$A_2 = (x + 4)^2 - 2^2$$
     Sous forme factorisée (différence de deux carrés) :
     $$A_2 = [(x + 4) - 2][(x + 4) + 2] = (x + 2)(x + 6)$$
     En développant l'expression initiale :
     $$A_2 = (x^2 + 8x + 16) - 4 = x^2 + 8x + 12$$

\section*{Corrigé -- Exercice 1 (5 points)}
1. Effectif total : $3 + 7 + 12 + 6 + 2 = 30$. \textbf{[0,75 pt]}\\
2. Classe modale : $[40 ; 60[$ (effectif 12). \textbf{[0,75 pt]}\\
3. Moyenne : $\bar{x} = \frac{3\times10 + 7\times30 + 12\times50 + 6\times70 + 2\times90}{30} = \frac{1440}{30} = 48$. \textbf{[1,50 pt]}\\
4. Médiane : La classe médiane est $[40 ; 60[$ ($15^e$ et $16^e$ valeurs). \textbf{[1,00 pt]}\\
5. Étendue : $100 - 0 = 100$. \textbf{[1,00 pt]}

\section*{Corrigé -- Exercice 2 (5 points)}
1. $CA_{2025} = 120\,000 \times 1{,}08 = 129\,600$ \texteuro{}. \textbf{[1,25 pt]}\\
2. a. $CM_{global} = 1{,}08 \times 0{,}95 = 1{,}026$. \textbf{[1,25 pt]}\\
b. $t_{global} = +2{,}6\,\%$. \textbf{[1,00 pt]}\\
3. Taux nécessaire : $\frac{150\,000}{129\,600} \approx 1{,}1574$, soit $+15{,}7\,\%$. \textbf{[1,50 pt]}

\section*{Corrigé -- Exercice 3 (5 points)}
1. $f(0) = 5$ et $f(2) = 9$. \textbf{[1,00 pt]}\\
2. Développement de $-(x-2)^2 + 9 = -x^2+4x-4+9 = -x^2+4x+5 = f(x)$. \textbf{[1,00 pt]}\\
3. Tableau de variations : maximum $9$ en $x=2$. \textbf{[1,25 pt]}\\
4. $f(x) = 5 \iff -x^2+4x = 0 \iff x(-x+4) = 0 \implies x=0$ ou $x=4$. \textbf{[1,00 pt]}\\
5. Tracé de la courbe. \textbf{[0,75 pt]}

\section*{Corrigé -- Exercice 4 (5 points)}
1. Arbre de probabilités (branches $G=0{,}4$, $\bar{G}=0{,}6$, $S$ sachant $G=0{,}6$, etc.). \textbf{[1,25 pt]}\\
2. $P(G \cap S) = 0{,}4 \times 0{,}6 = 0{,}24$. \textbf{[1,00 pt]}\\
3. $P(S) = 0{,}24 + (0{,}6 \times 0{,}5) = 0{,}54$. \textbf{[1,25 pt]}\\
4. $P_S(\bar{G}) = \frac{0{,}30}{0{,}54} = \frac{5}{9} \approx 55{,}6\,\%$. \textbf{[1,50 pt]}

# Exercice sur les identités remarquables

Cet exercice complet permet de travailler l'utilisation des trois identités remarquables fondamentales en calcul littéral.

## Énoncé de l'exercice

On considère les expressions littérales suivantes, définies pour tout nombre réel $x$ :

$$A = (3x + 2)^2$$

$$B = (5x - 4)(5x + 4)$$

$$C = (2x - 3)^2 - (x + 1)(x - 1)$$

1. Développer et réduire l'expression $A$.
2. Développer et réduire l'expression $B$.
3. Développer et réduire l'expression $C$.
4. Factoriser l'expression $D = 9x^2 - 25$.

---

## Rappels de cours

Pour rappel, les trois identités remarquables utilisées dans cet exercice sont :

* Carré d'une somme : $(a + b)^2 = a^2 + 2ab + b^2$
* Carré d'une différence : $(a - b)^2 = a^2 - 2ab + b^2$
* Produit de la somme par la différence : $(a - b)(a + b) = a^2 - b^2$

---

## Correction détaillée

### Question 1 : Développement de $A$
L'expression $A = (3x + 2)^2$ est de la forme $(a + b)^2$ avec $a = 3x$ et $b = 2$.

$$A = (3x)^2 + 2 \times (3x) \times 2 + 2^2$$
$$A = 9x^2 + 12x + 4$$

### Question 2 : Développement de $B$
L'expression $B = (5x - 4)(5x + 4)$ est de la forme $(a - b)(a + b)$ avec $a = 5x$ et $b = 4$.

$$B = (5x)^2 - 4^2$$
$$B = 25x^2 - 16$$

### Question 3 : Développement de $C$
L'expression $C = (2x - 3)^2 - (x + 1)(x - 1)$ combine le carré d'une différence et un produit remarquable.

* Développons $(2x - 3)^2$ : $(2x)^2 - 2 \times (2x) \times 3 + 3^2 = 4x^2 - 12x + 9$.
* Développons $(x + 1)(x - 1)$ : $x^2 - 1^2 = x^2 - 1$.

En remplaçant dans $C$ :
$$C = (4x^2 - 12x + 9) - (x^2 - 1)$$
$$C = 4x^2 - 12x + 9 - x^2 + 1$$
$$C = 3x^2 - 12x + 10$$

### Question 4 : Factorisation de $D$
L'expression $D = 9x^2 - 25$ est de la forme $a^2 - b^2$ avec $a = 3x$ et $b = 5$.

$$D = (3x)^2 - 5^2$$
$$D = (3x - 5)(3x + 5)$$

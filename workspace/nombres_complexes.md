Nombres Complexes : De l’Algèbre à la Géométrie


# Diapositive 2

Diapositive 1 : Introduction et Forme Algébrique L’unité imaginaire $i$ : Définie par $i^2 = -1$. Forme algébrique : Tout nombre complexe $z$ s’écrit de manière unique sous la forme : $z = a + ib$ où : $a$ est la partie réelle (notée $\text{Re}(z)$). $b$ est la partie imaginaire (notée $\text{Im}(z)$). Cas particuliers : - Si $b = 0$, $z = a$ est un nombre réel (ex: $z = 5$). - Si $a = 0$ et $b \neq 0$, $z = ib$ est un imaginaire pur (ex: $z = 3i$).


# Diapositive 3

Diapositive 2 : Représentation Géométrique et Conjugué Affixe d’un point ou d’un vecteur : Dans un repère orthonormal, le nombre $z = 3 + 4i$ est représenté par le point $M(3, 4)$ ou le vecteur $\vec{u}$ de coordonnées $(3, 4)$. Conjugué d’un nombre complexe : Défini par $\bar{z} = a - ib$. (ex: si $z = 3 + 4i$, alors $\bar{z} = 3 - 4i$). Propriété géométrique : $\bar{z}$ est le symétrique de $M$ par rapport à l’axe réel. Module d’un nombre complexe : Noté $|z|$, il correspond à la distance $OM$. (ex: $|3 + 4i| = \sqrt{3^2 + 4^2} = 5$).


# Diapositive 4

Diapositive 3 : Forme Trigonométrique et Exponentielle Forme trigonométrique : $z = r(\cos\theta + i\sin\theta)$ avec $r = |z|$ et $\theta = \arg(z)$ (argument modulo $2\pi$). (ex: pour $z = 1 + i$, $r = \sqrt{2}$ et $\theta = \frac{\pi}{4}$, donc $z = \sqrt{2}(\cos\frac{\pi}{4} + i\sin\frac{\pi}{4})$). Forme exponentielle : $z = r e^{i\theta}$. (ex: $1 + i = \sqrt{2} e^{i\frac{\pi}{4}}$). Très utile pour simplifier les multiplications et les puissances (formule de Moivre).


# Diapositive 5

Diapositive 4 : Applications et Résolution d’Équations Équations du second degré : Dans $\mathbb{C}$, toute équation $az^2 + bz + c = 0$ (avec $a \neq 0$) admet des solutions, même si le discriminant $\Delta < 0$. Si $\Delta = -4 < 0$, les solutions complexes conjuguées sont par exemple pour $z^2 + 1 = 0$ : $z_1 = i$ et $z_2 = -i$. Conclusion : Un pont magnifique entre algèbre, géométrie et trigonométrie ! 🎯

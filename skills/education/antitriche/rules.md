# Règles du Skill /antitriche

- Toujours s'assurer que les valeurs numériques du Sujet B ont été choisies pour que les calculs restent élégants (discriminants carrés parfaits, racines entières ou fractions simples).
- Séparer nettement les énoncés élèves des corrigés professeurs.
- Respecter le programme officiel de la classe demandée.
- Utiliser les commandes LaTeX officielles du gabarit : `\sujet{A}`, `\sujet{B}`, `\exo{...}{...}` et `\partie{...}`.
- Ne jamais ajouter de méta-commentaire sur les fichiers générés dans la réponse textuelle.

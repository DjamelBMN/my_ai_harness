# Règles du Skill /exercice

- Toujours vérifier la faisabilité mathématique des calculs (pas de division par zéro, discriminant vérifié, dérivées exactes).
- Formuler les questions avec les verbes d'action officiels ("Démontrer", "En déduire", "Justifier").
- Si une source officielle ou une annale récente est mentionnée, utiliser l'outil `web_search` pour vérifier la conformité.
- Écrire le livrable dans `workspace/exercice_<theme>.tex` et fournir le corrigé complet.

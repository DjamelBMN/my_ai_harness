# PROGRAMME DE MATHÉMATIQUES — CLASSE DE SECONDE GÉNÉRALE ET TECHNOLOGIQUE
Source officielle : Ministère de l'Éducation Nationale

## 1. Nombres et Calculs
- Ensembles de nombres : $\mathbb{N} \subset \mathbb{Z} \subset \mathbb{D} \subset \mathbb{Q} \subset \mathbb{R}$.
- Arithmétique élémentaire : Multiples, diviseurs, parité, nombres premiers, décomposition en facteurs premiers.
- Calcul littéral : Développement, factorisation (identités remarquables $(a+b)^2 = a^2+2ab+b^2$, $(a-b)^2 = a^2-2ab+b^2$, $(a-b)(a+b) = a^2-b^2$).
- Puissances et racines carrées : Règles de calcul ($a^n a^m = a^{n+m}$, $\sqrt{ab} = \sqrt{a}\sqrt{b}$ pour $a, b \ge 0$).
- Intervalles de $\mathbb{R}$, encadrements, valeur absolue $|x| = \text{dist}(x, 0)$, inéquations du type $|x - a| \le r$.
- Pourcentages : Proportion, pourcentages d'évolution, coefficient multiplicateur $CM = 1 + \frac{t}{100}$, évolutions successives et réciproques.

## 2. Fonctions
- Notion de fonction, variable, image, antécédent, courbe représentative.
- Sens de variation d'une fonction sur un intervalle : croissante, décroissante, constante.
- Fonctions de référence :
  - Fonction affine : $f(x) = mx + p$ (pente $m$, ordonnée à l'origine $p$).
  - Fonction carré : $f(x) = x^2$ (décroissante sur $\mathbb{R}^-$, croissante sur $\mathbb{R}^+$, parité paire).
  - Fonction inverse : $f(x) = \frac{1}{x}$ (strictement décroissante sur $]-\infty, 0[$ et sur $]0, +\infty[$, parité impaire).
  - Fonction racine carrée : $f(x) = \sqrt{x}$ (strictement croissante sur $[0, +\infty[$).
  - Fonction cube : $f(x) = x^3$ (strictement croissante sur $\mathbb{R}$, parité impaire).
- Résolution graphique et algébrique : Équations $f(x) = k$, inéquations $f(x) \ge k$, tableaux de signes pour les produits et quotients.

## 3. Géométrie
- Coordonnées d'un point dans un repère orthonormé : Milieu d'un segment $I\left(\frac{x_A+x_B}{2}, \frac{y_A+y_B}{2}\right)$, distance $AB = \sqrt{(x_B - x_A)^2 + (y_B - y_A)^2}$.
- Vecteurs du plan : Translation, égalité de vecteurs, somme vectorielle (relation de Chasles, règle du parallélogramme), multiplication par un réel.
- Coordonnées de vecteurs : $\vec{AB}(x_B - x_A, y_B - y_A)$.
- Colinéarité : Deux vecteurs $\vec{u}(x, y)$ et $\vec{v}(x', y')$ sont colinéaires si et seulement si leur déterminant est nul : $\det(\vec{u}, \vec{v}) = xy' - yx' = 0$.
- Droites du plan : Vecteur directeur $\vec{u}(-b, a)$, équation cartésienne $ax + by + c = 0$, équation réduite $y = mx + p$.

## 4. Statistiques et Probabilités
- Statistiques descriptives : Effectifs, fréquences, moyenne, médiane (valeur qui partage la série en deux sous-groupes de même effectif), quartiles $Q_1$ et $Q_3$, étendue, écart interquartile $Q_3 - Q_1$.
- Probabilités élémentaires : Événement, univers $\Omega$, équiprobabilité $P(A) = \frac{\text{Card}(A)}{\text{Card}(\Omega)}$, réunion $A \cup B$, intersection $A \cap B$, formule $P(A \cup B) = P(A) + P(B) - P(A \cap B)$, événement contraire $P(\bar{A}) = 1 - P(A)$.
- Échantillonnage : Fluctuation d'échantillonnage, simulation sur Python.

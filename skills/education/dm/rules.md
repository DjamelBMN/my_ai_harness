# Règles du Skill /dm (Devoir Maison)

- Si un format Word (.docx) est demandé : utiliser obligatoirement `generate_docx` pour créer directement le document Word dans le workspace sans créer de fichier `.tex`.
- Par défaut (ou si PDF demandé) : le template LaTeX `template_dm.tex` doit être respecté.
- Toujours vérifier que les fonctions auxiliaires proposées ont des racines ou des extrema calculables exactement ou encadrables sans ambiguïté.
- Intégrer les barèmes ou points indicatifs par question.
- Écrire le livrable dans `workspace/dm_<classe>_<theme>.tex` et fournir le barème/corrigé dans le chat ou en fichier joint.

# Model — Skill du Harness

Commande de supervision du ModelRouter. /model status affiche seulement les providers, modèles, disponibilités et présence des credentials, jamais leur valeur. /model gemini, mistral, openai ou ollama épingle un provider disponible pour les missions suivantes. /model auto réactive le routage automatique. Claude reste indisponible tant que son provider réel n'est pas connecté.
